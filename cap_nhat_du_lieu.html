🔄 Công cụ cập nhật dữ liệu Dashboard

Dùng khi bạn được cấp quyền cộng tác viên trên GitHub và muốn tự cập nhật dữ liệu — không cần cài đặt gì, chỉ cần trình duyệt.

Bước 1 — Tạo file dữ liệu mới

Công cụ sẽ tự lấy dữ liệu hiện tại của các nguồn khác, chỉ thêm/cập nhật đúng file bạn chọn — không làm mất dữ liệu của người khác.

    Lưu ý

    • Bấm "💾 Lưu (Sau khi thêm file)" để cập nhật thẳng cho tất cả mọi người, không cần rời trang này.
    • File Excel cần có sheet tên đúng "Tổng hợp theo nhóm" với cấu trúc giống file mẫu.
