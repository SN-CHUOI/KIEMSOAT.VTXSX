🔄 Công cụ cập nhật dữ liệu Dashboard

Dùng khi bạn được cấp quyền cộng tác viên trên GitHub và muốn tự cập nhật dữ liệu — không cần cài đặt gì, chỉ cần trình duyệt.

Bước 1 — Dán "chìa khóa" của bạn (chỉ cần làm 1 lần)

Cần được mời làm Collaborator trên repo này trước (báo người quản trị mời bạn qua email). Sau đó tự tạo chìa khóa riêng của bạn:

  1. 1Vào: github.com/settings/personal-access-tokens/new
  2. 2Repository access → chọn Only select repositories → chọn KIEMSOATVATU.XSX
  3. 3Permissions → Repository permissions → tìm Contents → chọn Read and write
  4. 4Bấm Generate token, copy đoạn mã hiện ra (bắt đầu bằng github_pat_)
  5. 5Dán vào ô bên dưới:

Bước 2 — Chọn file Excel và lưu

Công cụ sẽ tự lấy dữ liệu hiện tại của các nguồn khác, chỉ thêm/cập nhật đúng file bạn chọn — không làm mất dữ liệu của người khác.

    Lưu ý

    • Bạn cần được mời làm Collaborator trên repo GitHub này trước thì token mới hoạt động — nếu chưa, báo người quản trị mời bạn.
    • Token của bạn chỉ được lưu trên trình duyệt của chính bạn (localStorage) — không gửi cho tôi hay bất kỳ máy chủ nào khác ngoài GitHub.
    • File Excel cần có sheet tên đúng "Tổng hợp theo nhóm" với cấu trúc giống file mẫu.
